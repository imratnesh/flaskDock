# flaskDock

## To run the docker
```sh
$ sudo apt install docker.io
$ sudo docker pull imratnesh/flask
$ sudo docker run -d -p 5000:5000 imratnesh/flask
```
Verify the deployment by navigating to your server address in your preferred browser.

```sh
127.0.0.1:5000
```
